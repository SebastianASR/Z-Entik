# Z-Entik

Z-Entik es un sistema HelpDesk TI Full Stack desarrollado bajo la marca personal Z Labs.

## Stack principal

- Frontend: React + TypeScript
- Backend: NestJS + TypeScript + Node.js
- Base de datos: PostgreSQL
- ORM: Prisma
- Autenticación: JWT + Hash de contraseñas + 2FA
- Infraestructura: Docker + GitHub Actions + Render
- Marca visual: Z Labs

## Estado del proyecto

Proyecto en etapa inicial de desarrollo.
